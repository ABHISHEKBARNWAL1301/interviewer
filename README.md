# Interviewer

Interviewer is an AI agent for technical interview practice, bringing interviews, a code editor, a whiteboard, and notes into one workspace.

It's being built to help developers explain their thinking, solve problems, discuss design tradeoffs, and learn from each interview.

## What it's being built for

- **Technical interviews:** Practice coding, debugging, SQL, and system design with follow-up questions based on your answers.
- **Code editor:** Write and run code, inspect test results, and discuss your approach with the agent.
- **Whiteboard:** Sketch architectures and data flows while working through system design questions.
- **Notes:** Keep explanations, code snippets, diagrams, and lessons from your sessions together.
- **Feedback:** Review strengths and gaps with feedback grounded in your answers and work.
- **Session history:** Revisit previous interviews and continue unfinished practice.

## The agent behind it

The project explores the engineering behind an LLM agent harness: the model-and-tool loop, tool execution, context management, session persistence, and error recovery.

## Status

Early development. The features above describe the intended product and are being built incrementally.
